# Промпт под видео

Скопируйте одну строку и вставьте своему агенту (Claude Code, Codex, Antigravity, Cursor — любому агенту с доступом к терминалу):

```
Прочитай репозиторий https://github.com/PavelDumbrao/ai-video-lesson-kit и выполни всё, что там написано.
```

Если агент не умеет ходить в интернет сам, дайте ему две строки:

```
git clone https://github.com/PavelDumbrao/ai-video-lesson-kit && cd ai-video-lesson-kit
Прочитай AGENTS.md и выполни всё, что там написано.
```

Дальше агент ведёт вас сам: спросит ключи, фото и тему первого ролика — и сделает остальное.
