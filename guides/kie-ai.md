# kie.ai: ключ, модели лица, цены

kie.ai — агрегатор моделей генерации по одному API-ключу: там есть и говорящие аватары (Kling Avatar, InfiniTalk, OmniHuman), и картинки (Nano Banana, GPT Image), и видео (Kling, Veo, Seedance). Для нас — лицо, при желании — фото-референсы.

## Подключение
1. Регистрация на https://kie.ai → API Key (https://kie.ai/api-key) → `KIE_AI_API_KEY` в `.env`.
2. Пополнить баланс на несколько долларов (оплата картой; принимаются обычные и виртуальные — по опыту автора).
3. Загрузка файлов (фото и куски аудио) идёт через их файловый сервис (`KIE_UPLOAD_BASE`, по умолчанию `https://kieai.redpandaai.co`) — `face/face_kie.py` делает это сам.

## Модели для лица
| Модель | Когда | Параметры |
|---|---|---|
| `kling-avatar` | по умолчанию; `pro` — 1080p для публикации, `standard` — 720p для пробы | фото + аудио ≤ 15 с + короткий промпт-контекст |
| `infinitalk` | если губы «съезжают» или фразы длинные | 480p / 720p |
| `omnihuman-1.5` | более живая мимика и жесты, попробовать на одном месте | фото + аудио |

Точные схемы `input` и цены — на https://docs.kie.ai (страницы моделей; агент читает их перед первым запуском). Цены меняются; ориентир: 10 мест по 10 с на `pro` — единицы долларов за ролик. Перед генерацией агент показывает число мест, секунды и ориентир стоимости.

## Правила
- `createTask` списывает кредиты — не повторять автоматически; `taskId` сохранять сразу; обрыв ожидания — продолжать опрос `recordInfo`, не создавать заново.
- Текст реплики в промпт не вставлять. Промпт — контекст на английском: «A person talking directly to the camera in a calm studio, natural expressions, slight nods».
- Фото анфас, без очков, нейтральный свет. Документы — никогда.
