# Modal: бесплатные кредиты, карта, когда брать

Проверено по https://modal.com/pricing 29.10.2026. Цифры могут измениться — посмотрите страницу перед регистрацией.

## Что это
Modal — облачные вычисления «функциями»: скрипт на Python поднимает десятки контейнеров, они рендерят куски ролика параллельно. В мае 2026 компания привлекла $355 млн при оценке $4,65 млрд (Reuters, Dealroom) — то есть это крупный и живой сервис.

## Тариф
- **Starter — $0 в месяц + оплата вычислений, и каждый месяц $30 бесплатных кредитов.** На наш рендер этого хватает примерно на 20–30 роликов в месяц (≈ $1 за 14-минутный ролик при 72 контейнерах по 8 ядер, по замерам автора).
- Лимиты Starter: 100 контейнеров одновременно, 10 GPU, 3 места в воркспейсе. Team — $250/мес + вычисления.
- В воркспейсе есть **лимит расходов** (spend limit): когда кредиты кончаются, задачи перестают запускаться с ошибкой `Workspace … has exceeded its spend limit`. Это нормально — ждём следующего месяца или переходим на Hugging Face.

## Карта
Modal просит привязать карту даже на бесплатном тарифе (защита от злоупотреблений, при нулевом использовании ничего не списывают). **По опыту учеников автора**: виртуальные и предоплаченные карты принимаются не всегда — пробуйте разные карты (виртуальная карта банка, карта другой платёжной системы). Это наблюдение, а не правило площадки; официальных ограничений Modal не публикует.

## Подключение (агент делает сам)
```bash
pip install modal
modal token new            # откроет браузер, логин — человек
python3 cloud/modal_render.py --project remotion --lesson N --out out/lessonN_2k.mp4 --chunks 72
```
Образ (node 22 + Chromium + ffmpeg + шрифты + Remotion) собирается при первом запуске несколько минут, дальше кэшируется.

## Когда брать Modal, а когда Hugging Face
- Hugging Face PRO есть → Hugging Face (основной путь, дешевле в 7 раз).
- Нет PRO, но есть Modal с кредитами → Modal (быстрее по времени: ~2,5 мин на ролик).
- Кончились кредиты Modal посреди месяца → Hugging Face или локально.
