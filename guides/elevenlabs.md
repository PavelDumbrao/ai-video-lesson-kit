# ElevenLabs: тариф, клон голоса, ключ

Проверено по https://elevenlabs.io/pricing 29.10.2026 (страница показывает скидки первого месяца — цифры ниже без скидок; уточните на странице).

## Тариф
- **Free** — $0, 10 000 кредитов в месяц, без коммерческих прав и без клона — только попробовать.
- **Starter — около $6 в месяц, 30 000 кредитов**, коммерческая лицензия, **Instant Voice Cloning** (клон с короткой записи). Для первых роликов достаточно: по замеру 29.10.2026 — 0,22 кредита за знак на v4 Turbo (тарифы обещают до 1) → 13-минутный ролик 3–14 тыс. кредитов → от двух до десяти роликов в месяц.
- **Creator — около $22 в месяц, ~121 000 кредитов**, плюс Professional Voice Cloning (клон по часовой записи, ещё точнее). Для серии роликов — этот.
- Неиспользованные кредиты на платных тарифах переносятся (до двух месяцев).

## Клон голоса (Instant)
1. Записать 1–2 минуты речи на телефон: тихая комната, без музыки, не читать — рассказывать, как обычно говорите. Можно несколько файлов.
2. Voices → Add a voice → Instant Voice Clone → загрузить → назвать → сохранить. Скопировать **Voice ID** (в карточке голоса).
3. Проверить: сгенерировать в кабинете короткую фразу на русском моделью **Eleven v4** — тембр узнаваем? Если нет, перезаписать образец (чаще всего виновата гулкая комната).

## Ключ
Profile → API Keys → Create → скопировать один раз. В `.env`: `ELEVENLABS_API_KEY=…`, `ELEVENLABS_VOICE_ID=…`. Ключ не показывать в чатах и не коммитить.

## Модель
`eleven_v4_turbo` — быстро и живо, теги эмоций, русский без акцента; `eleven_v4` — ещё выразительнее, но медленнее и дороже. Формат `wav_48000`. Всё это уже зашито в `scripts/tts_timeline.py`.

## Карта
Принимает обычные и виртуальные карты; оплата подпиской.
