# Сколько стоит один ролик

Ориентиры по замерам автора (октябрь 2026), 14-минутный ролик 2K с 16 сценами графики и 13 местами лица. Для 3-минутного ролика делите примерно на четыре.

| Слой | Сервис | Ориентир | Примечание |
|---|---|---|---|
| Голос | ElevenLabs Starter / Creator | 3–14 тыс. кредитов (замер 29.10: 0,22 кредита за знак на v4 Turbo) | подписка $6–22/мес |
| Лицо | kie.ai (Kling Avatar pro) | единицы долларов | самая дорогая часть; цены — docs.kie.ai |
| Графика | токены вашего агента | 16 саб-агентов × 15–25 мин | зависит от подписки на агента |
| Проверка сцен | Hugging Face Jobs | ≈ $0.003 за проверку, 30–50 проверок ≈ $0.15 | |
| Рендер 2K | Hugging Face Jobs, 72 воркера | ≈ $0.13 | Modal ≈ $1 (из бесплатных $30/мес) |
| Фото-референсы | kie.ai (Nano Banana) | центы | один раз |
| **Итого за ролик** | | **единицы долларов** | без учёта подписок |

Подписки на старте: ElevenLabs Starter (~$6) + Hugging Face PRO ($9) или Modal ($0 + кредиты) + баланс kie.ai ($5–10). Время: первый 3-минутный ролик — 30–60 минут с настройкой; дальше 14-минутный — около часа работы агента без вас.
