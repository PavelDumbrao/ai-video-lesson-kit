# Hugging Face: подписка PRO, задачи (Jobs), карта

Проверено по официальным страницам 29.10.2026: https://huggingface.co/pricing и https://huggingface.co/docs/hub/billing. Цифры могут измениться — перед оплатой посмотрите страницу сами.

## Что это и зачем нам
Hugging Face — самая большая площадка открытых нейросетей. Нам нужны **Jobs** — облачные задачи на их процессорах: мы запускаем 72 задачи одновременно, каждая рендерит свой кусок ролика, и 14-минутный ролик 2K готов за 3,5–6 минут вместо 1–3 часов на ноутбуке.

## Тариф
- **PRO — $9 в месяц.** Даёт: в 8 раз большую квоту ZeroGPU (бесплатные видеокарты для Spaces — пригодятся для своих моделей), $2 включённых кредитов на инференс в месяц, приватные Spaces с Docker и Dev Mode, расширенное хранилище.
- **Jobs и Spaces-железо оплачиваются по факту** сверх подписки: `CPU Upgrade` (8 vCPU, 32 ГБ) — **$0.03 в час**, минимальная тарификация — минута. Наш рендер: 72 задачи × ~4 минуты ≈ 263 задаче-минуты ≈ **$0.13** за ролик (расчёт автора по замерам). Проверка одной сцены ≈ $0.003.
- Бесплатного аккаунта для Jobs недостаточно — нужен PRO (или организация с биллингом).

## Карта
Для PRO и оплаты по факту нужно привязать карту в Settings → Billing. По опыту автора и учеников Hugging Face принимает обычные и виртуальные карты без проблем. Ничего не списывается, пока задачи не запущены; можно поставить **лимит расходов** в биллинге — поставьте (например $5), это настоящий предохранитель, а не только `--budget` в скрипте.

## Что сделать один раз (агент делает сам, человек — только логин и карта)
1. Settings → Access Tokens → New token, тип **write** → `HF_TOKEN` в `.env`; `huggingface-cli login` или файл `~/.cache/huggingface/token`.
2. Создать **приватный датасет** `video-render-assets` (New → Dataset): туда летят бандлы и куски рендера. `HF_DATASET=<user>/video-render-assets`.
3. Создать **приватный Space** `remotion-speed-worker` (New → Space → SDK **Docker**), положить `cloud/worker/Dockerfile` и `render_chunk.py`, рядом `package.json`/`package-lock.json` из `remotion/`, дождаться сборки (5–10 минут). Это образ воркера: node 22, Chromium, ffmpeg, шрифты, Remotion. `HF_WORKER_IMAGE=hf.co/spaces/<user>/remotion-speed-worker`. Пересобирать при смене версии Remotion.
4. Проверка: `python3 cloud/hf_render.py … --dry-run` печатает план без оплаты; `--live` запускает.

## Нюансы
- Одновременных задач на PRO хватает на 72 воркера (автор проверял 72; 100 — только пробные запуски).
- Hugging Face медленнее Modal примерно в 2,5 раза по времени (5,5 мин против 2,2), но в 7 раз дешевле ($0.13 против $0.92) — поэтому основной путь.
- Задачи платные с первой минуты: не запускайте `--live` без плана и цены.
- Если токен без права write — выгрузка бандла в датасет упадёт.
