# Помощники сцен: `src/motion/utils.ts`

Общие кирпичики, которые агенты сцен раньше писали сами (урок 29: 14 своих `safeExitAlpha`, 6 своих `Page`).
Всё — чистые функции кадра: без хуков, без замеров DOM. Импорт из сцены: `import { Pages, Slot, StampFit, safeExitAlpha } from "../../utils";`

| Помощник | Что делает |
|---|---|
| `safeExitAlpha(f, bNext?, fade=10)` | 1, пока не пришёл следующий бит; линейно к 0 за `fade` кадров **до** `bNext` (ровно 0 на `bNext`); `bNext` нет — всегда 1 |
| `<Pages f starts>{(i, st) => …}</Pages>` | рисует только страницу, которой принадлежит кадр; старая уходит за `fadeOut=8`, пауза `gap=2`, новая входит за `fadeIn=10` |
| `<Page f starts i>` / `pageState` / `pageLook` | то же по одной странице или числами (`alpha`, `y`, `p`, `q`) — для своей анимации |
| `<Slot f at w h x y label icon>{элемент}</Slot>` | пунктирная плашка «ждёт» до бита, на бите плавно сменяется элементом в той же рамке |
| `<StampFit f start text maxW maxH x y>` | `Stamp` из ui.tsx, который не вылезает из коробки: кегль сам ужимается, удар 2.1× обрезан по коробке |
| `stampStyle(f, at, {w, h, maxW, maxH, rot})` | тот же «удар» для своего бейджа известного размера |
| `clampIn(x, lo, hi)`, `stampBox`, `rotBox` | держать бейдж внутри карточки: `x = clampIn(want, 24, cardW - 24 - box.w)` |

## Пример: 3 страницы × 4 бита

```tsx
const TITLES = ["Шаг 1: ключи", "Шаг 2: голос", "Шаг 3: рендер"];
export const Demo: React.FC<SceneProps> = ({ f, b, t0 }) => {
  const P = [t0, b[4], b[8]]; // начала страниц: первая — с t0, дальше — на первом бите страницы
  return (
    <Pages f={f} starts={P}>
      {(i) => (
        <>
          <Heading f={f} at={P[i]} x={140} y={130} title={TITLES[i]} size={38} />
          {[0, 1, 2, 3].map((k) => (
            <Slot key={k} f={f} at={b[i * 4 + k]} x={140 + k * 415} y={250} w={395} h={570} label={`пункт ${k + 1}`}>
              <Frame w={395} h={570} kind="plain">
                <StampFit f={f} start={b[i * 4 + k] + 12} text="ГОТОВО" x={24} y={440} maxW={347} maxH={110} />
              </Frame>
            </Slot>
          ))}
        </>
      )}
    </Pages>
  );
};
```
`Heading` и `Frame` — из `scenes/hc1/kit` и `ui`. Заголовок общей шапки меняйте так же: `<Pages>` внутри блока шапки.

## Какие грабли закрыты

- **Наложение заголовков при смене страницы** — две страницы никогда не видны в одном кадре: старая видна до `starts[i+1] − gap − 1`, новая — с `starts[i+1]`.
- **Пустой кадр между страницами** — пауза ровно `gap` кадров (по умолчанию 2; `gap={0}` — стык в стык); последний кадр ухода ещё виден (линейный уход, без «невидимого хвоста»).
- **Пустые слоты до появления элемента** — `Slot` держит место плашкой с подписью, раскладка не прыгает; элемент монтируется только со своего бита.
- **Штампы за краем карточки** — `StampFit` считает ширину по реальным метрикам Montserrat 900 (с запасом, кернинг не вычитается) и учитывает поворот, рамку и кольцо.
- **«Чёрная дыра» после лица** — не гасите графику по границе окна лица: только `safeExitAlpha(f, bNext)`; последний бит не гаснет, сцена уходит сама на `t1`.

## Важно

- В l29 Leadgen / Frames / Control / Motion / Forums / Harness / Hook / Outro свои `safeExitAlpha` **начинают** гаснуть на `bNext`; библиотечный **заканчивает** к `bNext`. Не смешивайте в одной сцене.
- `starts` — по возрастанию; страница короче `fadeIn + fadeOut + gap` (~20 кадров) не успеет проявиться полностью.
- Последняя страница не уходит — её уводит `SceneLayer` на `t1`.
