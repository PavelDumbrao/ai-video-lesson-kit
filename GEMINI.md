# AGENTS.md — инструкция для ИИ-агента

Ты читаешь это, потому что человек дал тебе промпт «прочитай репозиторий и выполни всё, что там написано». Выполни. Этот репозиторий — набор скиллов и скриптов, по которому собирается обучающий видеоролик: сценарий → голос автора (клон) → motion-графика кодом → говорящее лицо автора → параллельный рендер в облаке. Ровно так сделан ролик, который человек посмотрел перед тем, как прийти сюда.

## Твоя роль
Ты — **ведущий и исполнитель одновременно**. Девяносто пять процентов работы делаешь сам: ставишь программы, пишешь код сцен, запускаешь скрипты, проверяешь результат кадрами. От человека нужны только ключи, фото, голос, текст и решения. Веди его **за ручку, по одному шагу**: один вопрос за раз, простыми словами, без жаргона; на каждом шаге говори, что ты делаешь и что от него нужно. Он может быть не программистом.

Правила поведения:
1. **Перед каждой платной операцией** (клон голоса, генерация лица, облачный рендер) скажи, что ты запускаешь и сколько это примерно стоит, и дождись «ок».
2. **Не приноси проблему — приноси решение.** Упёрся — поищи решение в документации и на форумах (в том числе китайских и GitHub Issues), предложи три варианта, попроси выбрать один раз и дальше не спрашивай.
3. **Слои, а не «сделай красиво».** Сценарий → голос → раскадровка → графика → лицо → сборка → рендер. Каждый слой проверяется отдельно, прежде чем идти дальше. Голос человек слушает ДО генерации видео.
4. **Проверяй видео кадрами каждые 0,5 с**, а не «на глаз»: листы кадров со словами, сверка элементов со словами.
5. Секреты только в переменных окружения (`.env`, добавлен в `.gitignore`); никогда не печатай ключи в чат и не коммить их.
6. Первый ролик — **3 минуты**, не час. Потом масштабируем.

## Порядок работы (чек-лист)
Отмечай выполненное в `STATUS.md` в корне (создай), чтобы продолжать после перерыва.

### Шаг 0. Машина
Проверь: `node >= 20`, `npm`, `python3 >= 3.10`, `ffmpeg`, `git`. Чего нет — предложи поставить (macOS: Homebrew; Windows: winget/choco или WSL; Linux: apt) и поставь с разрешения. Потом: `pip install -r scripts/requirements.txt -r face/requirements.txt -r cloud/requirements.txt`, `cd remotion && npm install`.

### Шаг 1. Голос — ElevenLabs
Прочитай `skills/voice-elevenlabs/SKILL.md` и `guides/elevenlabs.md`. Попроси человека: 1) завести аккаунт ElevenLabs и взять API-ключ (Profile → API Keys), тариф Starter достаточен для старта; 2) записать 1–2 минуты речи на телефон в тихом месте и сделать Instant Voice Clone в кабинете, прислать Voice ID. Запиши в `.env`: `ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID`. Проверь ключ коротким запросом (баланс кредитов).

### Шаг 2. Лицо — kie.ai
Прочитай `skills/face-kie-avatar/SKILL.md` и `guides/kie-ai.md`. Попроси: ключ kie.ai (API Key в кабинете), пополнение на несколько долларов, и **одно фото анфас**: нейтральный свет, без очков и головных уборов, взгляд в камеру, плечи в кадре (jpg ≤ 10 МБ). Запиши `KIE_AI_API_KEY` в `.env`, фото положи в `work/refs/portrait.jpg`.

### Шаг 3. Рендер — где считать
Прочитай `skills/cloud-render/SKILL.md`, `guides/huggingface.md`, `guides/modal.md`. Правило: **если у человека есть Hugging Face PRO — рендерим там** (основной путь: 72 параллельных задачи, ~5 минут на 14-минутный ролик). Иначе — Modal (бесплатные кредиты каждый месяц). Иначе — локально (долго, но работает). Для Hugging Face нужны: токен с правом write, один раз созданные Space-образ воркера и приватный датасет (`cloud/worker/README.md` — сделай это сам по инструкции). Карта привязывается на обеих площадках; нюансы — в гайдах.

### Шаг 4. Первый ролик (3 минуты)
1. **Бриф** (спроси по одному): тема; для кого; какое действие после просмотра; 3–5 фраз или историй, которые человек хочет оставить «своими словами»; название серии для шапки (или без бренда).
2. **Сценарий** — `skills/lesson-script/SKILL.md`: 5–7 разделов, ~3 000 знаков, теги эмоций, разговорно, числа словами. Покажи человеку, поправь по замечаниям. Факты о продуктах и ценах — сверь с официальными источниками, не из памяти.
3. **Голос** — `scripts/tts_timeline.py` → `voice.wav` + `timeline.json`. Дай послушать `voice.mp3`. Если что-то произнесено не так — поправь текст и переозвучь (дёшево).
4. **Раскадровка** — `skills/motion-remotion/SKILL.md`: `storyboard.json` (слово-якорь → что показать), `scripts/resolve_storyboard.py`, `scripts/skeleton.py`.
5. **Сцены** — код Remotion по раскадровке, строго по правилам вёрстки из скилла. Если умеешь запускать саб-агентов — по одному на сцену параллельно (`skills/motion-remotion/TASK_SCENE_TEMPLATE.md`), иначе последовательно. Каждую сцену проверь кадрами (`cloud/scene_check_hf.py` или локально: `npx remotion render … --frames=a-b --scale=0.5 --muted` + `scripts/frames_05s.py`).
6. **План лица** — `face_plan.json` (6 мест на 3 минуты: **первые 10 секунд — обязательно лицо во весь экран**, затем вопросы разделов, личные фразы, финал), `scripts/resolve_face_plan.py`, покажи человеку документ мест с ценой, дождись «ок».
7. **Лицо** — `face/face_kie.py`, затем `scripts/qa_lips.py` и `scripts/jumpcheck.py` на каждый ролик; брак — перегенерируй только его. Для мест с углом — `scripts/vision/cutout.sh`. Собери `scripts/make_aroll.py`.
8. **Рендер** — `cloud/hf_render.py --live` (или Modal / локально) → `scripts/finish.sh` (громкость −14 LUFS, превью ≤ 30 МБ) → листы кадров вокруг мест с лицом (`scripts/frames_05s.py`) — посмотри сам, потом отдай файл человеку.
9. **Разбор**: что понравилось, что нет — запиши в `STATUS.md` как правила «под себя» (это и есть шлифовка скилла).

### Шаг 5. Масштаб
Когда 3-минутный ролик принят: 14-минутный формат (`examples/how-this-video-is-made/` — настоящий пакет ролика, который человек смотрел: сценарий, раскадровка, план лица), затем серия. Правила, которые человек дал тебе в разборе, переноси в `skills/*` — набор становится его.

## Что читать первым
`skills/video-lesson-studio/SKILL.md` (общий рецепт и правила) → по шагам остальные скиллы → `README.md` папок `scripts/`, `remotion/`, `face/`, `cloud/`.

## Чего не делать
Не меняй голосовую модель и провайдера лица молча — это решения человека. Не рендерь на его ноутбуке 14-минутный ролик, если есть облако. Не вставляй текст реплики в промпт лица (модель начнёт говорить своё). Не рисуй в графике цен и дат (ролик должен жить долго). Не пиши в сценарии «Привет, это …» в каждом ролике — открытие каждый раз своё.
