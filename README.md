# ai-video-lesson-kit — видеоурок с вашим голосом и лицом, который собирает ваш ИИ-агент

Этот набор — тот самый скилл, по которому сделан ролик «Как сделано это видео: ИИ-студия за час»: голос — клон автора, графика — код, лицо — модель, рендер — 72 облачных воркера. Никакой камеры, монтажёра и дизайнера. Вы ставите задачу — агент делает.

## Как начать (1 минута)
Вставьте своему агенту одну строку (Claude Code, Codex, Antigravity, Cursor — любому агенту с терминалом):

```
Прочитай репозиторий https://github.com/PavelDumbrao/ai-video-lesson-kit и выполни всё, что там написано.
```

Дальше агент читает `AGENTS.md` и ведёт вас за ручку: спросит ключи, фото и тему первого ролика, сам поставит программы, напишет сценарий, озвучит, нарисует графику, сгенерирует лицо, отрендерит в облаке и отдаст файл. От вас — ключи, фото, голос, текст и «ок» перед платными шагами.

| Компьютер | любой: node ≥ 20, python ≥ 3.10, ffmpeg, git (агент поставит) | — |

Полная смета — `guides/costs.md`. Карта привязывается на всех площадках; нюансы (виртуальные, предоплаченные) — в гайдах.

## Как это устроено: слоёный пирожок
1. **Сценарий** — разделы, теги эмоций, ваши фразы дословно (`skills/lesson-script`).
2. **Голос** — ElevenLabs v4 Turbo, одна сплошная дорожка + тайминги слов (`skills/voice-elevenlabs`).
3. **Раскадровка и графика** — «слово → элемент», сцены Remotion кодом, по агенту на сцену параллельно, проверка кадрами каждые 0,5 с (`skills/motion-remotion`).
4. **Лицо** — фото + кусок голоса → ролик 8–12 с; во весь экран или бесшовно в угол поверх графики; проверка губ и склеек (`skills/face-kie-avatar`).
5. **Рендер** — изолированный бандл → 72 воркера на Hugging Face → склейка, звук, −14 LUFS, превью (`skills/cloud-render`).
Главный рецепт и правила — `skills/video-lesson-studio/SKILL.md`.

## Структура
```
AGENTS.md            инструкция агенту: роль «ведущий за ручку», чек-лист шагов
PROMPT.md            промпт под видео
skills/              скиллы (рецепт, сценарий, голос, графика, лицо, рендер) + шаблон ТЗ сцены
scripts/             инструменты конвейера (озвучка, раскадровка, каркас, лицо, проверка, сборка, финиш)
remotion/            проект графики (библиотека сцен, караоке, слой лица, переходы)
face/                адаптер лица через kie.ai
cloud/               рендер на Hugging Face Jobs / Modal, облачная проверка сцен, образ воркера
guides/              Hugging Face, Modal, ElevenLabs, kie.ai, смета
examples/how-this-video-is-made/   настоящий пакет ролика: сценарий, раскадровка, план лица, тайминги
```

## Первый ролик
3 минуты, 5–7 разделов, 6 мест с лицом — 30–60 минут вместе с настройкой. Потом 14-минутный формат и серия. После каждого ролика говорите агенту, что не так — он превращает это в правило в `skills/`, и набор становится вашим.

## Правило 72 часов
Если за три дня не сделали первый ролик — не вернётесь. Сделайте сегодня. Застряли — напишите в ProAI Community (ссылка под видео), разберём вместе.
