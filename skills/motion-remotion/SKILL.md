# Графика: Remotion по раскадровке

Проект — `remotion/` (библиотека `src/motion/*`, композиция `Lesson.tsx`: караоке внизу, плашки разделов, кикер серии, слой лица `Aroll.tsx`, переходы `Transition.tsx`). Урок N = данные `public/lessonN/{timeline,storyboard,aroll,screens}.json` + сцены `src/motion/scenes/lN/`.

## 1. Раскадровка `storyboard.json`
На раздел — одна сцена со своим `type` (`lN_<имя>`), 6–12 битов `[слово-якорь, что показать]`. Якорь — слово из текста раздела (префикс, без пунктуации, ё = е); биты идут по порядку. Label — ТЗ на элемент: что появляется в момент слова и остаётся до конца сцены.
```json
{"29": [{"section": 0, "type": "l29_hook", "beats": [["Лицо", "титул слева: «КАК СДЕЛАНО ЭТО ВИДЕО»"], ["минуты", "таймер «3 ч → 3 мин»"]]}]}
```
`python3 scripts/resolve_storyboard.py storyboard.json --timeline audio/timeline.json --out remotion/public/lessonN/storyboard.json` — переводит якоря в секунды, падает, если якорь не найден (переформулировать якорь, не текст).
Правила раскадровки: без цен и дат; названия продуктов текстом, без логотипов; биты не ставить внутрь окон лица «во весь экран»; в сценах с углом — в label писать «слева/справа (угол занят лицом)».

## 2. Каркас
`python3 scripts/skeleton.py N --project remotion --sub "Название"` — заглушки сцен `() => null` по типам из раскадровки, регистрация в `scenes/index.ts` и `src/lessons.ts`, пустые `aroll.json`/`screens.json`. Данные `voice.wav`, `timeline.json` — в `public/lessonN/`. Проверка: `npx tsc --noEmit`, `npx remotion compositions src/index.ts` показывает `LessonN`.

## 3. Сцена
Файл `src/motion/scenes/lN/<Имя>.tsx`, `export const <Имя>: React.FC<SceneProps>`. `SceneProps`: `f` (кадр), `b[]` (кадры битов: элемент бита появляется на `b[i]`), `t0`/`t1` (вход/уход сцены), `w(prefix)` (кадр слова), `scene`, `tl`. Библиотека: `anim.ts` (пружины, stagger), `ui.tsx`, `text.tsx`, `icons.tsx`, `viz.tsx`, `constants.ts` (`LAYOUT`, `ANIM_TIMING`), `utils.ts` — `safeExitAlpha`, `Pages`/`Page` (смена страниц без наложений и пустых кадров), `Slot` (заглушка до своего бита), `StampFit` (штамп в пределах карточки); как пользоваться — `src/motion/README-helpers.md`. Свои копии этих помощников в сценах не писать.

### Строгие правила вёрстки (каждое — грабли, записанные один раз)
1. Кадр 1920×1080; сцена в зоне **x 140–1780 / y 130–830**; ниже y 860 — только караоке.
2. Палитра из `theme.ts`: фон `#111318`, карточки `#232833`, текст `#F3EFE6`, акцент `#FFB300`, серый `#9AA0AA`; `#4ADE80`/`#F87171` — только галочки и ошибки. Шрифты Montserrat + JetBrains Mono через компоненты.
3. **Шапка сцены**: `display: "flex", justifyContent: "space-between", alignItems: "flex-start"`. Запрещено `alignItems: "flex-end"` — при переносе заголовка чипы врезаются в карточки.
4. **Заголовок ≤ 38 px**; контейнер карточек строго с **y 250** (высота 570); зазор ≥ 35 px; отступы карточек `26px 34px`, плашек `14px 20px`.
5. **Нет «чёрных дыр»**: элемент живёт до своего следующего бита — `safeExitAlpha(f, bNext)`; не гасить графику по границе окна лица. Пустой фон дольше 3 с (кроме окон лица во весь экран) — брак.
6. **Плотность**: зона заполнена; нет полосы только сверху и пустоты ниже y 560 дольше 3 с; заголовки карточек ≥ 32 px, текст ≥ 24 px, ключевые числа 48–72 px. Если на листе 960×540 не читается — мелко.
7. **Ничего друг на друге**: новый бит не ложится на старый элемент; нет места — старый уезжает или новый ниже.
8. **Угол лица**: во время окна «в углу» зона (справа x 1220–1920, слева x 0–700; y 280–850) свободна **с первого кадра окна**; сдвиг композиции заканчивается до окна.
9. Караоке и текст — **без микро-скейла** (дрожит базовая линия); активное слово только цветом и тенью; `translateY` округлять до целых.
10. Всё детерминировано; без blur на больших площадях; без логотипов брендов; без цен и дат.

## 4. Параллельные саб-агенты (16 сцен за ~30 минут)
По одному агенту на сцену, каждый в своей рабочей копии (`git worktree add -b lN-aNN work/lNw/aNN <ветка>`; `node_modules` и `public` — симлинки на основной проект). ТЗ — `skills/motion-remotion/TASK_SCENE_TEMPLATE.md` (заполнить номер урока, сцену, отрезок, окна лица). Агент пишет только свой файл и **сам проверяет сцену кадрами**; не больше 3 кругов; отчёт по форме. Сборка: файлы сцен → основной проект → `npx tsc --noEmit` → коммит.

## 5. Проверка кадрами (обязательно)
- Облако (предпочтительно, машина не нагружается): `python3 cloud/scene_check_hf.py <рабочая копия> N <от с> <до с> --stills t1,t2 --tag lNaNN` → `scene-check/<tag>/sheet_NN.jpg` (6×4 кадра каждые 0,5 с с секундой голоса) + `still_<t>.png`. 2–5 минут, ≈ $0.003.
- Локально (короткий ролик, один агент): `npx remotion render src/index.ts LessonN /tmp/r.mp4 --frames=a-b --scale=0.5 --muted` → `python3 scripts/frames_05s.py /tmp/r.mp4 --offset <от с>`.
- Смотреть **все** листы и стиллы: элемент бита виден сразу после своего слова; ничего не обрезано и не налезает; угол свободен; нет мигания и пустых кусков; в караоке не лезет.

## 6. После лица
Когда `aroll.json` собран (`face-kie-avatar`), посмотреть листы вокруг каждого места с лицом ±1 с: переходы «в угол» и обратно, графика под углом, стык в паузе после речи.

Образец: `examples/how-this-video-is-made/storyboard.json` (16 сцен, 129 битов) и сцены `remotion/src/motion/scenes/l1/` (ролик «Как сделано это видео»).
