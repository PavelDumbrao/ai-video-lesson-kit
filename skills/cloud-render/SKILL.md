# Рендер в облаке

## Правило выбора
1. **Есть Hugging Face PRO → рендерим на Hugging Face Jobs.** Основной путь. 72 параллельных задачи `cpu-upgrade` ($0.03/час каждая): 14-минутный ролик 2K за 3,5–6 минут, ≈ $0.13 (замеры автора). Проверка сцен — тоже там.
2. Нет PRO, есть Modal → `cloud/modal_render.py` (Starter даёт бесплатные кредиты каждый месяц; 72 контейнера по 8 ядер: ~2,5 мин, ≈ $1 за ролик по замерам автора).
3. Ничего нет → локально `npx remotion render … --concurrency <ядра>` — 14 минут 2K на 8 ядрах ≈ 1–1,5 часа. 3-минутный ролик — 15–20 минут, терпимо.
GPU не нужен: Remotion в облаке его не использует (проверено автором: +4 % на L4).

## Один раз: подготовка аккаунта Hugging Face
1. Токен с правом write (`HF_TOKEN`), `huggingface-cli login` или `~/.cache/huggingface/token`.
2. Приватный датасет `video-render-assets` (ассеты: бандлы, чанки, результаты проверок) — `HF_DATASET=<user>/video-render-assets`.
3. Space-образ воркера `remotion-speed-worker` (SDK Docker, приватный) из `cloud/worker/` — node 22, Chromium (прогрет на сборке), ffmpeg, шрифты, `/rt/node_modules` из `remotion/package.json`, `render_chunk.py`. `HF_WORKER_IMAGE=hf.co/spaces/<user>/remotion-speed-worker`. Сборка Space 5–10 минут, один раз; пересобирать при смене версии Remotion.
4. Карта в биллинге (списания по факту, при нуле — ничего). Подробно — `guides/huggingface.md`, `cloud/worker/README.md`.

## Рендер урока
```bash
python3 cloud/hf_render.py --project remotion --lesson N --comp LessonN --audio remotion/public/lessonN/voice.wav --workers 72 --out out/lessonN_2k.mp4 --budget 0.50 --dry-run   # план и цена
python3 cloud/hf_render.py … --live                                                                                                                          # запуск
```
- **Изолированный бандл**: в облако уходит только `public/lessonN` + шрифты + json остальных уроков (45–55 МБ вместо гигабайт). Без этого выгрузка убивает параллельность.
- Кадры делятся на 72 равных куска; каждая задача рендерит свой без звука; склейка `-c copy` за секунды; звук = `voice.wav` со сдвигом 500 мс (голос начинается с кадра 15).
- Масштаб ровно `1.3333333333333333` (1920×1080 → 2560×1440); `1.3333` даёт нецелую высоту и падение.
- Бюджет — программный предохранитель; реальный лимит ставится в биллинге HF. Перед `--live` показать человеку план и цену.
- Обрыв связи / упавший кусок — повтор только этого куска (ledger), не всего рендера.

## Проверка сцены в облаке (во время разработки графики)
`python3 cloud/scene_check_hf.py <рабочая копия> N <от с> <до с> --stills t1,t2 --tag lNaNN` → листы 6×4 кадра каждые 0,5 с с секундой голоса и стиллы 1920×1080; 2–5 минут, ≈ $0.003. Перед первым вызовом и после изменения медиа урока (голос, ролики лица, вырезы): `python3 cloud/scene_check_hf.py --sync N`. 16 агентов могут проверять одновременно — коммиты в датасет повторяются при конфликте.

## Финиш
```bash
bash scripts/finish.sh out/lessonN_2k.mp4 out/lessonN_final_2k.mp4      # −14 LUFS двухпроходно (видео копируется), превью 720p ≤ 30 МБ одним проходом
python3 scripts/frames_05s.py out/lessonN_final_2k.mp4 --around aroll.json  # листы вокруг мест лица ±1 с
```
- Превью не кодировать кусками — заметен «пульс» качества; только одним проходом.
- Мастер 2K — исходник для публикации; копия 1080p — только по просьбе.
- Перед выдачей посмотреть листы вокруг каждого места с лицом и стыки разделов.

## Modal (запасной)
`pip install modal && modal token new` → `python3 cloud/modal_render.py --project remotion --lesson N --out out/lessonN_2k.mp4 --chunks 72`. Образ собирается при первом запуске (несколько минут). Нюанс карт — `guides/modal.md`.
