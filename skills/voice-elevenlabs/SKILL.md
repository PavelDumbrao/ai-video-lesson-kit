# Голос: ElevenLabs v4 Turbo + клон автора

## Почему так
По опыту автора v4 Turbo даёт самый живой русский голос за разумные деньги: теги эмоций, паузы, тембр. Голос клонируется с 1–2 минут записи (Instant Voice Clone доступен на тарифе Starter; Professional Voice Clone — на Creator и выше; см. `guides/elevenlabs.md`). Модель менять без решения человека нельзя.

## Подготовка (один раз)
1. Человек: аккаунт → Profile → API Keys → ключ. Тариф Starter — достаточно для старта (≈ 30 000 кредитов в месяц — от двух до десяти 13-минутных роликов (замер: 0,22 кредита за знак); точные условия — на странице тарифов).
2. Человек: записать 1–2 минуты обычной речи на телефон в тихой комнате (без музыки, не читать монотонно — рассказывать), загрузить в Voices → Add → Instant Voice Clone, скопировать Voice ID.
3. `.env`: `ELEVENLABS_API_KEY=…`, `ELEVENLABS_VOICE_ID=…`. Проверка ключа: `GET https://api.elevenlabs.io/v1/user/subscription` (показывает остаток кредитов).

## Озвучка
```bash
set -a; . .env; set +a
python3 scripts/tts_timeline.py work/lessonN/script.md work/lessonN/audio --stability 0.25
```
- Модель `eleven_v4_turbo`, формат `wav_48000` (максимум качества), `stability` 0.25 — живее (0.55 — ровнее).
- На выходе: `voice.wav` (главный звук ролика), `voice.mp3`, `timeline.json` (слова с секундами, строки караоке, разделы, ключевые слова).
- Файл сценария обязан начинаться с `## Раздел`, иначе API вернёт «empty text».
- Текст > 9 000 знаков: разбить по разделам на части (каждая начинается с `## `), озвучить части параллельно, склеить `python3 scripts/merge_timeline.py out part1 part2` (пауза 0,5 с между частями).
- Теги `[warm]`, `[laughs]` и т. п. — английские, в квадратных скобках; они не звучат. Если в результате слышно слово тега — тег написан неправильно.

## Проверка (обязательно, до видео)
1. Человек слушает `voice.mp3`. Это дешёвый слой — переозвучить раздел стоит копейки; видео — дорого.
2. Whisper-сверка (если есть локальный `whisper-asr-webservice` или любой STT): совпадение слов ≥ 0,93 — норма; расхождения допустимы только в числах цифрами и английских терминах. Пропущенные фразы, звучащие теги, символы, прочитанные словом («стрелка») — переозвучить раздел. `scripts/qa_lips.py --whisper-url` использует тот же сервер.
3. Переозвучка одного раздела: раздел отдельным файлом → `tts_timeline.py` → `scripts/splice_section.py` (если есть) или пересборка частей; остальной голос побайтно прежний — ролики лица не перегенерируются.

## Громкость
Голос ElevenLabs имеет пики на ~20 дБ выше средней; финиш нормализует до −14 LUFS линейно (по факту −15…−16 LUFS, чистый звук). Лимитер не ставить — звук «качается».

## Расход
Замер 29.10.2026: 1 020 знаков на v4 Turbo = 224 кредита (≈ 0,22 за знак); страница тарифов обещает «до 1 кредита за знак» — считайте по факту первой озвучки. 13-минутный ролик ≈ 3–14 тыс. кредитов. Перед озвучкой агент называет число знаков и примерный расход.
