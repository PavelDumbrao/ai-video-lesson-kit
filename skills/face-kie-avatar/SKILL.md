# Лицо: kie.ai, план мест, проверка, сборка

## Идея
Лицо — отдельный слой поверх графики. Модель получает **фото** + **кусок нашей аудиодорожки** и возвращает ролик 8–12 с, где губы попадают в звук. В финал идёт только наш голос; звук ролика выбрасывается. Провайдер — сменный: в наборе kie.ai (один ключ, доступен всем), у автора — другая модель; остальной конвейер не меняется.

## 1. План мест `face_plan.json`
```json
{"places": [
  {"id": "F01", "section": 0, "from": "То что", "to": "стоял", "mode": "full→corner", "switch": "Лицо", "side": "right", "why": "хук во весь экран, затем угол"},
  {"id": "F02", "section": 1, "from": "Извините", "to": "человека", "mode": "full", "why": "личная реплика"}
]}
```
- Окно места: от слова `from` до конца предложения со словом `to` (якорь — слово или фраза из 2–3 слов). Окно ≤ 11,2 с; речи в окне ≥ 5 с (короткую фразу брать вместе с соседней).
- `mode`: `full` — вставка во весь экран на жёсткой склейке; `full→corner` — весь экран, затем на слове `switch` бесшовно в угол (`side` left|right), графика видна; `corner→full` — наоборот (финал).
- Где ставить: **первое место — всегда с первой секунды ролика и не короче 10 с (`full→corner`)**; дальше вопрос раздела, личная фраза, шутка, финал (`corner→full`). Формула автора на 3 минуты: ~6 мест, ≈ 30–40 с; на 13 минут: 12–13 мест, 4–5 переходов. Окна — в паузах между фразами; биты графики не попадают в окно «во весь экран».
- `python3 scripts/resolve_face_plan.py face_plan.json --timeline timeline.json --out plan.json` → секунды, `dur` 8–12, `switch_t`. Проверить, что окна не пересекаются.
- **Документ мест с ценой — человеку до генерации** (список мест, секунды, модель, ориентир стоимости по тарифу kie.ai).

## 2. Фото-референс
Один кадр анфас: нейтральный свет, взгляд в камеру, плечи в кадре, без очков и головных уборов, без надписей на фоне, jpg ≤ 10 МБ, **горизонтальный 16:9** (ролик лица приходит в пропорциях фото; вертикальное фото `face_kie.py` дополнит до 16:9 размытыми краями — работает, но настоящий фон по бокам смотрится лучше). В проверочном прогоне набора (светло-серый однотонный фон, светлая кожа, лысая голова) вырез для угла потерял половину лица — PP-HumanSeg плохо отделяет кожу от близкого по яркости фона; для мест «в угол» берите фон, контрастный коже, и обязательно смотрите лист кадров угла. Лучше реальное фото в той одежде и обстановке, которые будут «студией» ролика. Ракурсы 3/4 и профиль модели переносят плохо — камера фронтальная.

## 3. Генерация
```bash
python3 scripts/make_face_chunks.py --plan plan.json --voice voice.wav --out work/face   # <id>.mp3 с тишиной 0,4 с по краям
python3 face/face_kie.py --plan work/face/plan.json --voice voice.wav --photo work/refs/portrait.jpg --out work/face/videos --model kling-avatar --quality pro
```
- Модели: `kling-avatar` (standard 720p / pro 1080p, до 15 с), `infinitalk` (480p/720p, точнее губы на длинных фразах), `omnihuman-1.5`. Первый пробный ролик — `kling-avatar standard` (замер 29.10.2026: 11 с = 88 кредитов ≈ $0,44), для публикации — `pro` 1080p; если губы «съезжают» — `infinitalk`.
- Промпт — только контекст (англ.): кто, где, как держится. **Текст реплики в промпт не вставлять** — модель начнёт говорить своё. Описывать только видимое: кивки, взгляд, ладонь; не «вздыхает/шепчет».
- `taskId` сохраняется сразу после создания; обрыв ожидания ≠ провал — продолжать опрос, не создавать задачу заново. Повтор `face_kie.py` пропускает готовые места.
- Все места отправляются разом (параллельно), 3–10 минут.

## 4. Проверка каждого ролика (бесплатно)
```bash
python3 scripts/qa_lips.py work/face/videos/F01.mp4 work/face/F01.mp3 work/face/F01.txt   # волна ≥ 0,7 по окнам 1 с, огибающая, Whisper если есть
python3 scripts/jumpcheck.py work/face/videos/F01.mp4                                     # скачок размера лица > 18 % = склейка / наезд
```
Плюс лист кадров 0,5 с глазами: лицо то же, нет надписей на фоне, рук/предметов лишних нет, нет смены плана. Важно только окно показа (`clipStart … clipStart + окно`); хвост после речи не считается — провал на последнем окне у конца речи почти всегда ложный (обрезать окно показа на 0,2–0,4 с). Брак — перегенерировать **только это место** спокойным промптом («говорит в камеру, лёгкие кивки, руки опущены, план не меняется»). Норма: 60–100 % с первой попытки.

## 5. Вырезы для переходов «в угол»
Для мест `full→corner` / `corner→full`: `bash scripts/vision/cutout.sh work/face/videos/F01.mp4 remotion/public/lessonN/trans/F01` → `_cutout.webm` (VP9 с альфой), `_face.json` (трек лица), `_matte.mkv`; `python3 scripts/vision/measure_body.py …_matte.mkv > …_body.json` (геометрия бюста для угла). Модели OpenCV Zoo ставит `scripts/vision/setup.sh`. ≈ 1 мин на ролик.

## 6. Сборка слоя
`python3 scripts/make_aroll.py --project remotion --lesson N --lab work/face F01=F01 F02=F02_b …` → `public/lessonN/aroll.json` (вставки `cut` с чередованием масштаба 1.0/1.15, переходы `trans` с ключами `full|corner|hidden`, сторона угла). Угол: бюст ≈ 630×560 над караоке, низ растворяется; чередовать сторону от ролика к ролику. После сборки — листы кадров вокруг каждого места ±1 с (`scripts/frames_05s.py`): стык в паузе после речи, угол не закрывает графику.

## Грабли
- Текст реплики в промпте → модель озвучивает сама (0 из 6). Блок про речь первым → то же. 
- Плоский скриншот как референс → второй «телефон в воздухе»; предметы — отдельным фото-референсом с предметом в руке.
- После последнего слова модель может добавить свой звук — стык ставить в паузу сразу после речи.
- Склейку/наезд на крупный план автопроверка губ не ловит — только `jumpcheck` и лист кадров.
- Фотографии документов — никогда.
